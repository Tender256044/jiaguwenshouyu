部署架构

一期单机 PC 部署，二期剥离为「小程序前台 + GPU 服务器后台」。

前端层小程序 / H5 / PC（只采集 + 渲染）

SQLite · Redis
数据层SVG 字形库 / 映射表 / 模型仓库

可剥离的 5 条硬约束：前端零 Python 依赖 · 接口 OpenAPI 契约化 · 模型路径外部化 · 推理层抽象 · 服务无状态。

关于「契语」

「契」——甲骨文刻写之意，亦指约定、信物；「语」——手语与语言。项目以受控词表为界，让每一句手语都能稳稳落成一片可考据的甲骨，服务听障沟通，活化冷门绝学。
